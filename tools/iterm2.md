# iterm2 -- 积累优先级：低
### iterm2是什么？
iTerm2 是 **macOS 平台免费开源的终端模拟器**，用来替代 Mac 系统自带的「终端（Terminal）」，底层依然调用bash/zsh/fish等shell. items shell更强、自定义能力拉满.

> 一句话区分：mac 自带终端是基础款；iTerm2 是专业增强版终端。

### iterm2合适哪些人用？
1. 程序员、算法工程师
2. 运维、后端，经常多窗口操作，登录多个服务器，同时查看日志
3. 重度命令行使用者，高频使用git、zsh、vim、tmux等命令
4. 喜欢折腾配置、定制终端样式、快捷键、Shell主题玩家

### 我主要使用item2的功能
1. 分屏。一个标签页自由横向\纵向切分多个独立终端面板。
    1. **cmd+shift+d 横向分屏**
    2. **cmd+d 纵向分屏**
    3. **cmd+option+方向键 可以在多屏中切换**
    4. **ctl+d 可以删除当前分屏**
2. 自动补全
    1. cmd+; 自动提取当前终端出现过的所有单词、路径、命令，快速补全，不用手打长路径；
3. 高度自定义外观
    1. 配速主题
    2. 透明度
    3. 背景模糊、背景图
    4. 字体、光标样式

### item2配置
样式配置 profile->颜色->dark
